## ✨ v2 주요 업그레이드
1. **🎯 연습 전 30초 영점 세팅 체크바**: `엄지·검지 힘 0%(악력 3)` · `52도 바운스 바닥 밀착` · `바닥 T자 정렬선`
2. **⛳ 50분 어프로치 정밀 분리**: `10~20m 런닝/칩샷 존(좁은 오픈·퍼터식 엄지그립)` vs `30~50m 피치샷 존(주먹 3개 스탠스·신체 4단계 포켓/허리/가슴/어깨·느린 다운스윙)` + **평지/오르막/내리막 라이 스위치**
3. **🏌️ 90분 인도어 실전화**: 임진한 솔(Sole) 마찰 30m 워밍업 · 소범준 토우 밸런스 & 왼쪽 허벅지 수직 낙하 · **임진한 드라이버 180m 컨트롤 ↔ 220m 정타 교대 훈련**
4. **🏠 집콕 5분 홈트레이닝**: 벽 골반 힌지 & 책 플레인 · 끝 묶은 수건 리듬 · 오른발 동전 압력 체크
5. **🆘 필드 SOS 닥터 탭**:
   - **스토아 멘탈 심폐소생술**: `24초(4-2-6) 실시간 호흡 가이드` + 4대 필드 멘탈 위기(초반 호조 자만, 티샷 해저드 직후, 맑은 시야 공포, 후반 10번홀 하체 방전) 스토아 주문
   - **7대 실전 미스샷 원탭 응급처방**: 드라이버 좌측 훅 / 우측 슬라이스 / 유틸·아이언 뒤땅·탑볼 / 아이언 좌측 당김 / 10~20m 냉온탕 / 30~50m 거리 오차 / 벙커 공포 (처방 사용 횟수가 데이터·Plaud 대본·Obsidian 마크다운에 자동 기록됨)
