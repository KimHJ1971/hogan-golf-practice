## ✨ v6 Atelier 신규 혁신 요소
1. **🎙️ 스튜디오 신경망 프로 보이스 팩 (`audio/` 265개 클립 · `-16 LUFS` 마스터링)**:
   - 기계음 브라우저 TTS(`speechSynthesis`)를 주 엔진에서 퇴출하고, 차분하고 명쾌한 투어 코치 화법(임진한·벤 호건 스타일)으로 전면 각색된 `ko-KR-SunHiNeural` MP3 오디오 팩을 직접 탑재했습니다.
   - 오프닝·매 타 레슨·스윙 큐·중간 체크·마무리·반응형 샷 피드백·연속 훅 리셋·영점/김형근 판독·5대 라이·4대 경사지·10대 SOS·24초 복압 호흡까지 오프라인 연습장에서도 **0ms 무지연** 재생됩니다(미로드 시 Web Speech API 자동 폴백).
2. **🥁 3:1 투어 템포 어쿠스틱 메트로놈 & 스튜디오 사운드 (`SoundStudio`)**:
   - 전자 비프음을 제거하고 로우패스 하모닉 차임과 **우드블록 3:1 투어 템포(`24:8` 표준 / `27:9` 여유 / `21:7` 빠름)** 를 실시간 합성해 백스윙–탑 스톱–임팩트 리듬을 청각·시각으로 동시에 동기화합니다.
3. **🎧 풀스크린 몰입형 '라이브 보이스 스튜디오' (`#liveStudioOverlay`)**:
   - `▶ 프라이빗 보이스 레슨 시작` 시 다크 딥그린 스튜디오 모드로 전환되어 **원형 SVG 타이머 링 · 실시간 보이스 웨이브폼 · 3:1 템포 트랙 · 17px 고대비 자막 · 장갑 친화 대형 원탭 기록 패드**를 제공합니다.
   - 최소화 시 상단 미니 스튜디오 바(`#miniStudioBar`)가 유지되어 교본이나 다른 탭을 오가도 끊기지 않습니다.
4. **🎨 5색 Atelier 디자인 시스템 & 클린 정보 계층**:
   - Deep Pinehurst Green(`#0B2218`) · Warm Linen(`#F7F5EF`) · Champagne Brass(`#C6A15B`) · Terracotta Clay(`#B84A39`) 팔레트와 커스텀 24px SVG 라인 아이콘 적용.
   - 과밀하던 상단 6버튼 그리드와 펼쳐진 체크박스를 **하단 5탭 바 (`연습` / `어프로치` / `퍼팅` / `필드 SOS` / `기록`)** 와 **프리-세션 요약 스트립 · 바텀시트 서랍(`#prepDrawerModal`)** 으로 깔끔하게 정리했습니다.
5. **⚡ 오프라인 Cache-First PWA (`sw.js` v8)**:
   - `hogan-golf-coach-v8` 서비스 워커가 `audio/*.mp3`를 **Cache-First**로 캐싱하고 Phase 시작 시 다음 타 클립을 백그라운드 프리캐시합니다.

## ⛳ 핵심 수록 커리큘럼 (기존 v5 원리 100% 보존)
- **김형근 10회 마스터스윙 복원**: 백스윙 머리 반 개(공 1.5개) 이내, 동시 출발·도착, 왼손등 펴기, 탑 하나—둘 스톱!, 상체 우측+하체 사선 뒤로 밀기, 골반 과회전 방지(배꼽 살짝 우측), 팔 몸 붙여 릴리스, 오른발 다 치고 들기, 드라이버 들림·덮임 차단, 연습 120% → 실전 30%, 쓸 수 있는 드로우 구분, 소파 사선 밀기(+발 떼기).
- **100m 이내 숏게임 & 헤드업 차단**: 뒤꿈치 넓은 스탠스·공 중앙, 평지 런 10m(오르막 5m·내리막 15m), 반동 없는 하나—둘 기다림, 웨지 커플링, 20m 러닝 왼쪽 힘 고정, 공 지나간 빈 잔디 끝까지 보기, Safe First 피라미드 + 52° 토샷.
- **3·6·9 퍼팅 공식 & 필드 SOS & 10초 복기/Plaud/Obsidian**: 보폭 기반 헤드 폭 계산기(느림/표준/빠름), 24초 복압 호흡 보이스 리드, 산악 4대 경사지, 10대 미스샷 처방, 손 쓰임 실험 모드(`hogan2026` vs `hk2021`) 연동.
