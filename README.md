## ✨ v3 (안정적 70타 마스터 에디션) 핵심 업그레이드
1. **🎯 연습·필드 전 30초 영점 세팅 v3**:
   - `호건 2너클 뉴트럴 + 오른손 중·약지 걸침(엄지·검지 힘 0% · 등속 악력 3)`
   - `앞바운스 성냥 켜기(옆그립 양어깨 수평)` & `에이프런 52° 토샷(힐 띄움)`
   - `공 앞 30cm 중간 타깃(오른손 페이스 선행 정렬) + 360° 복압 코어 세팅`
2. **🏌️ 90분 인도어 연습장 (좌측 풀훅 박멸 & 인조 매트 착시 검증)**:
   - **매트 착시 3대 검증 체크**: 공 뒤 12cm 수건/명함 뒤땅 검증 · 1시 방향 고무티 게이트 · 공 앞 매트 타격음 확인
   - **좌측 훅 근본 교정**: `백스윙 8시 스퀘어 점검` → `왼엉덩이 7시 벽 확보` → `1시 방향 푸시 익스텐션`
   - **전 클럽 단일 엔진 기준**: 드라이버~웨지 모두 **그립 끝 왼쪽 허벅지 안쪽 통일** + 드라이버 `180m 컨트롤 ↔ 220m 레이백 푸시드로우` 교대 훈련
3. **⛳ 50분 어프로치 — 100m 이내 완전 정복 매트릭스**:
   - **"핀은 함정! 1m 랜딩 박스" 전략** + **5대 지형·타법 스위치**(`평지`, `오르막`, `내리막·포대`, `에이프런 52° 토샷`, `깊은 러프·디봇`)
   - **9구간 세밀 거리 매트릭스**: `10m, 15m, 20m(Safe First 굴리기)` · `30m⭐(캐리20+런10 기준점), 40m, 50~60m(L-to-L)` · `70~80m(10시-2시), 90m+(80% 컨트롤), 그린사이드 벙커`
4. **🕳️ 10분 퍼팅 — 과학적 '3·6·9 퍼터 헤드 폭' & 그린 스피드 계산기**:
   - `3·6·9걸음 = 퍼터 헤드 1·2·3개 폭 백스윙` + `느림(×1.25) / 표준(×1.0) / 빠름(×0.8)` 즉석 보정 계산기
   - 박세리 등속 '공 태우기' 템포 + 백현범 '왼쪽 눈 수직 & 공 앞 20cm 통과문' + 내리막 변곡점(Apex) 삼각형 시각화
5. **🏠 집콕 5분 홈트레이닝 v3**:
   - `360° 복압 실린더 & 벽 골반 힌지` · `끝 묶은 수건 양어깨 터치 리듬` · `오른발 안쪽 동전 압력 & 2cm 뒤 세팅`
6. **🆘 필드 SOS 닥터 v3 & ⚡ 장갑 안 벗는 10초 원탭 종료 위저드**:
   - **스토아 24초 복압 호흡** + **4대 멘탈 위기 처방(추위·후반 체력 방전 포함)**
   - **⛰️ 한국 산악지형 4대 경사지 3초 공식 스위치** (`발보다 높은 공 / 낮은 공 / 왼발 오르막 / 왼발 내리막`)
   - **10대 실전 미스샷 원탭 응급처방 & Before/After 비교 도해**
   - **⚡ 10초 원탭 종료·복기 위저드**: 장갑을 벗어 타이핑할 필요 없이 칩 터치만으로 정타율·구질·핵심 큐를 저장하고 Plaud 음성 대본 및 Obsidian 마크다운 일지로 즉시 내보내기 지원
