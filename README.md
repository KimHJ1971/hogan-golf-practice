# 🏌️ 벤 호건 싱글디짓 연습 가이드 (Hogan Golf Coach PWA)

**90분 인도어 연습장 · 50분 어프로치 연습장 · 10분 퍼팅 연습장** 실전 타이머, 벤 호건 스윙 큐(등 근육·견갑골 시동, 왼발 체중 칩샷, 좌측 훅 경보, 3/4 비상 컨트롤 티샷), **Plaud 음성메모 대본 생성기**, 그리고 **Obsidian 마크다운 변환기**를 탑재한 모바일 웹앱(PWA)입니다.

## 🔗 모바일 실행 주소 (GitHub Pages)
👉 **https://kimhj1971.github.io/hogan-golf-practice/**

### 📲 핸드폰 홈 화면에 앱으로 설치하기
1. 핸드폰 브라우저로 위 주소에 접속합니다.
2. **아이폰(Safari)**: 하단 공유 버튼 `[↑]` → **`홈 화면에 추가`**
3. **갤럭시/안드로이드(Chrome)**: 우측 상단 메뉴 `[⋮]` → **`앱 설치`** 또는 **`홈 화면에 추가`**
4. 설치 후에는 연습장에서 오프라인 상태에서도 단독 앱으로 작동하며, 기록은 휴대폰 내부에 자동 저장됩니다.
